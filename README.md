# Privacy Policy

This Privacy Policy informs you of our policies about the information collected when you use the Service. By using the Service, you agree to the collection and use of information in accordance with this Privacy Policy.

### The information we collect

- **Discord account data**: user ID, username, display name and server nickname.
- **Server data**: server (guild) IDs, channel IDs, and the roles you have in servers where the Bots are used (for example level, donor or booster roles), used to unlock features and perks.
- **Game data**: statistics extracted from EPIC RPG commands and replies, such as command counts, drops, XP, levels, pets, duels, dungeons, arena and miniboss participation, quests and cooldowns.
- **Feature settings you provide**: for example highlight keywords, reminder settings, private channel owners/members, and marriage/partner settings.
- **Server activity logs**: in the RPG Army server only, which invite was used when a member joins, and server boost start/end.

### Message content

The Bots read the content of messages in the channels they can see **only** to:

- detect EPIC RPG commands you type (for example `rpg hunt`, `rpg dungeon`) and the Bots' own text commands; and
- read the replies of the EPIC RPG bot (text and embeds) to extract the game values listed above.

Message text is processed in memory and **is not stored**; only the extracted values (numbers, item names, IDs) are saved. Highlights compare messages against the keywords you configured and notify you, without storing the message.

Message content and all other data are **not** used to train machine learning or AI models.

### How we use your information

This information is used only to provide the functionality of the Bots: solving dungeons, tracking statistics and game progress, levels and roles, lists and giveaways, reminders, and leaderboards.

Usernames, display names or server nicknames may be displayed in leaderboards and other features of the Bots, which all users have access to.

### Storage and sharing

Data is stored in databases on the servers that host the Bots and is only accessible to the Bots' operators. It is **not sold or shared** with anyone else.

### Data retention and deletion

Data is kept while you use the Bots so your progress and statistics are preserved. You can stop the Bots from collecting new data at any time by not using them.

The pet assistant of Army Helper is the feature that stores your data. You can delete all of it yourself at any time with the `tdelete` command (`t` is the default prefix; use your server's prefix if it was changed).

For any other data, you can request deletion by emailing the contact below with your Discord user ID; requests are handled within 30 days.
